# Daylist

A clean, responsive to-do list that keeps your tasks in your browser with `localStorage`—no account or server required.

## Use it

Open `index.html` in a modern browser. Add tasks, mark them done, filter the list, delete individual tasks, or clear all completed tasks. Your list is saved automatically and will still be there when you return using the same browser and device.

## Notes

- Tasks are stored in this browser under `daylist.tasks.v1`.
- Clearing browser site data or using a different browser/device will remove or not include the saved list.
- The app uses plain HTML, CSS, and JavaScript; there are no build steps or dependencies.
